# 세법 원문 (자동 수집)

블로그 원고의 조문 대조는 이 폴더를 grep 해서 한다. 국회 심의 중인 개정안·시행 예정 조문은 여기 없다.
시행규칙의 별표·서식(이미지·첨부파일)은 본문에 들어 있지 않다.
